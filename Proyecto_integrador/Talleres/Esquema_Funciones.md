# Implementación de Código del Sistema COMPOST-IoT

## 1. Introducción
En esta sección se detalla la arquitectura de software desarrollada para el funcionamiento integral del prototipo. El sistema computacional se divide en dos entornos principales: el firmware embebido en el microcontrolador (ESP32) programado en C++ para la adquisición de señales, control de actuadores y conexión Wi-Fi/MQTT; y la aplicación móvil desarrollada en Flutter (Dart) encargada de la visualización remota, gestión de alertas y la interacción gamificada con el usuario.
