| **20/08/26** | E | **Función Principal:** CompostTech monitorea y controla las condiciones del compostaje midiendo temperatura, humedad, pH y gases. El sistema compara las lecturas con rangos establecidos y, mediante una pantalla LCD, alerta al usuario para que corrija la condición, verificando el resultado posteriormente. Adicionalmente, incluye una página web y una aplicación móvil como dashboard remoto para consultar en tiempo real el estado del compost, historial de mediciones y alertas.  |          **A.A, R.T** |
| **8/11/26** | E | **Geometría:**El dispositivo deberá presentar un diseño compacto, portátil y resistente a las condiciones propias de una compostera. El prototipo estará compuesto por una unidad de control, sensores, sistema de alimentación y elementos de visualización o comunicación. Como requerimiento de diseño, el dispositivo completo no deberá superar aproximadamente: \*0.40 m × 0.30 m de base y 0.50 m de altura.\* Los sensores deberán ubicarse de manera estratégica dentro de la compostera para obtener mediciones representativas sin interferir significativamente con el proceso de descomposición. La estructura deberá permitir retirar los sensores para realizar mantenimiento, limpieza o calibración. |            **A.A, R.T** |
| **8/09/20** | E | **Cinemática:** El sistema tendrá un funcionamiento principalmente electrónico y no requerirá mecanismos de movimiento continuo. Los sensores permanecerán ubicados en puntos determinados del compost y realizarán mediciones periódicas. El usuario será responsable de las intervenciones físicas, como: \* Voltear el compost. \* Agregar agua. \* Incorporar material seco. \* Mezclar los residuos. El dispositivo únicamente detectará las condiciones y comunicará al usuario cuándo se recomienda realizar estas acciones |           **A.A, R.T** |
| **9/09/26** | E | **Fuerzas**: El sistema no generará fuerzas mecánicas significativas sobre el compost, debido a que no contará con mecanismos automáticos de volteo ni sistemas de dosificación. La estructura deberá soportar: \* Peso de los sensores. \* Peso del controlador. \* Elementos de protección. \* Sistema de alimentación. Los sensores deberán estar correctamente fijados para evitar desplazamientos o daños durante el volteo manual del compost. |           **A.A, R.T** |
| **23/0826** | E | **Condiciones Ambientales:** El sistema monitorea las condiciones internas del compost según rangos biológicos para descomposición aerobia eficiente \[4\]: Temperatura: fase mesófila 20–35 °C; fase termófila 35–65 °C. Alerta si permanece \<55 °C durante más de 3 días (sanitización). Humedad: óptima 50–70 %. Alerta si \<45 % (inhibición microbiana) o \>70 % (anaerobiosis). pH: monitorear tendencia a la neutralidad (\~7). Alerta si \<5,5 o \>8,5.   |  |
| **10/09/26** | E | **Energía**: El sistema deberá trabajar con \*bajo consumo energético\*, debido a que estará compuesto principalmente por sensores, un microcontrolador y un sistema de comunicación. El prototipo podrá utilizar una fuente de alimentación de baja tensión o una batería recargable. El consumo deberá mantenerse reducido mediante mediciones periódicas y modos de bajo consumo cuando el sistema no se encuentre realizando una lectura. Los componentes electrónicos deberán estar protegidos contra humedad y contacto directo con el material orgánico.\[2\]   |         **A.A, R.T** |
| **10/09/20** | E | **Materia:**  **Materia de ingreso:** El sistema estará destinado al monitoreo de residuos orgánicos biodegradables utilizados para producir compost, tales como: \* Restos de frutas. \* Restos de verduras. \* Hojas. \* Residuos de poda. \* Restos vegetales. \* Otros residuos orgánicos adecuados para compostaje. **Materia de salida:** El proceso tendrá como producto final \*compost estabilizado\*, destinado potencialmente a utilizarse como acondicionador o enmienda del suelo. El sistema no modifica directamente la materia orgánica; únicamente monitorea las condiciones bajo las cuales ocurre su descomposición. |           **A.A, R.T** |
| **26/09/26** | E | **Señales (Información)**:  El sistema contará con señales de entrada y salida que permitan conocer el estado del proceso. **Señales de entrada**  Señal de inicio:  Se inicia el proceso de monitoreo. Señal de parada: Se detienen las mediciones. Señal de temperatura: Se obtiene mediante el sensor correspondiente. Señal de humedad: Se obtiene mediante el sensor de humedad. Señal de pH: Se obtiene mediante el sensor de pH. Señal de gases: Se obtiene mediante el sensor de gases. Señal de conexión:  Permite verificar la comunicación entre el sistema y la plataforma IoT.  **Señales de salida**:  Señal de condición óptima: Se indica que los parámetros se encuentran dentro de los rangos establecidos. Señal de humedad baja:  Se recomienda agregar agua manualmente. Señal de humedad elevada: Se recomienda revisar y airear el compost. Señal de temperatura inadecuada:  indica que se debe revisar el proceso. Señal de pH inadecuado: Indica una condición que requiere evaluación. Señal de alerta: Informa al usuario sobre una condición que requiere intervención. Señal de pérdida de comunicación: Informa cuando el dispositivo deja de transmitir datos.\[3\] |         **A.A, R.T** |
| **11/09/26** | E | **Control:**  El sistema de control deberá permanecer estable durante las diferentes etapas del proceso de compostaje. El ESP32 recibirá la información de los sensores y procesa los datos mediante un algoritmo de decisión. El algoritmo comparará las mediciones con los rangos previamente establecidos. El funcionamiento será: Medición → procesamiento → comparación → clasificación → alerta. Por ejemplo: Humedad baja → condición detectada → alerta → “Se recomienda agregar agua”. Humedad elevada \+ temperatura baja → condición detectada → alerta → “Se recomienda airear el compost”. El sistema deberá considerar no solamente el valor instantáneo de cada variable, sino también su tendencia en el tiempo, con el objetivo de evitar alarmas innecesarias por cambios momentáneos.\[3\] |            **A.A, R.T** |
| **11/09/26** | E | **Electrónico (hardware):**  El sistema utilizará componentes electrónicos de bajo costo y disponibles comercialmente. Los principales componentes serán: ESP32: Controlador principal y comunicación inalámbrica. Sensor de temperatura: Medición de la temperatura interna del compost. Sensor de humedad: Determinación del contenido de humedad. Sensor de pH: Evaluación de la condición ácido-base. Sensor de gases: Monitoreo complementario de cambios gaseosos. Módulo de alimentación: Suministro de energía al sistema. Pantalla OLED o LCD: Visualización local de los parámetros. LEDs indicadores: Identificación rápida del estado del proceso. Buzzer: Generación de una alerta local. Caja protectora: Protección de los componentes electrónicos. El ESP32 integrará las señales provenientes de los sensores y procesa la información mediante el algoritmo desarrollado. Los datos podrán ser enviados mediante Wi-Fi a una plataforma IoT, permitiendo al usuario visualizar las condiciones del compost desde un dispositivo móvil o computadora.\[5\] |  **A.A, R.T** |
| **10/09/26** | E | **Software:** El sistema deberá contar con un programa encargado de: 1\. Recibir las lecturas de los sensores. 2\. Procesar y almacenar los datos. 3\. Comparar las mediciones con los rangos establecidos. 4\. Identificar condiciones normales o anormales. 5\. Analizar las tendencias de las variables. 6\. Generar alertas. 7\. Mostrar el estado general del compost. 8\. Registrar el historial de mediciones. El software deberá clasificar el estado del compost en diferentes niveles: 🟢 Óptimas: condiciones adecuadas. 🟡 Advertencia: existe una condición que debe ser revisada. 🔴 Intervención: se recomienda realizar una acción sobre el compost.\[5\]   |  **A.A, R.T** |
| **11/09/26** | E | **Comunicaciones:** Comunicaciones: El ESP32 establecerá comunicación directa y estable con los sensores (temperatura, humedad, pH y gases) mediante conexiones cableadas (I2C, OneWire, ADC), garantizando adquisición de datos sin interferencias. Asimismo, el ESP32 procesará y almacenará las señales recibidas, e interpretará las instrucciones del usuario mediante la interfaz de control.Adicionalmente, el sistema utilizará la conectividad Wi-Fi del ESP32 para transmitir datos hacia una plataforma IoT en la nube, permitiendo la visualización remota en tiempo real a través de un dashboard web, una aplicación móvil con gráficos interactivos y una pantalla OLED interactiva local \[8\].  |  **A.A, R.T** |
| **10/09/26** | E | **Seguridad:** Para evitar riesgos de cortocircuito o daños por el entorno húmedo del compostaje, la carcasa externa que aloja el microcontrolador y la pantalla debe cumplir con el grado de protección IP65 (protección total contra polvo y chorros de agua) \[1\]. Además, el sistema deberá operar obligatoriamente a un voltaje de seguridad bajo (5V \- 12V DC) para eliminar cualquier riesgo de choque eléctrico para el usuario al momento de regar o manipular la biomasa | J.M   |
| **11/09/26** | E | **Ergonomía:** La altura y disposición para el manejo del equipo y de sus dispositivos de mando se establecerán considerando las características antropométricas de los usuarios, de manera que permitan un acceso y manipulación adecuados sin generar posturas o esfuerzos que puedan comprometer la salud. Para determinar las dimensiones y disposición del equipo se tomará como referencia la norma **ISO 7250-1:2017, Basic human body measurements for technological design**, que proporciona medidas antropométricas aplicables al diseño de espacios y equipos de trabajo \[6\]. Asimismo, se considerarán los principios ergonómicos establecidos en la **ISO 6385:2016**, orientados a garantizar condiciones de trabajo que favorezcan el bienestar, la seguridad y la salud del usuario \[7\].  | B.M |
| **11/09/26** | E | **Fabricación:** El sistema se fabricará con materiales y componentes electrónicos comerciales de fácil reposición en el mercado nacional, con plazos de importación entre 5 a 15 días \[11\], \[12\]. El gabinete y soportes se elaborarán mediante manufactura local utilizando polímeros resistentes al impacto y a la degradación térmica \[11\]. Asimismo, las sondas en contacto con el compost serán anticorrosivas, libres de emisión de sustancias tóxicas (según el D.S. Nº 007-98-SA, art. 37\) \[12\] y con acabados superficiales de fácil limpieza bajo la norma ISO 468 \[13\].   | B.M |
| **11/09/26** | E | **Control de calidad:** El sistema garantizará la confiabilidad en la adquisición de datos mediante sensores con calibración certificada que aseguren un margen de error máximo de  ±5% en humedad relativa ±1°C, en temperatura y ±2 en pH, asegurando mediciones representativas para el control de las etapas biológicas \[14\]. Previo al ensamblaje definitivo, el circuito integrado (ESP32 y sensores) se someterá a un ensayo de operación continua durante 24 horas para evaluar la estabilidad térmica de la placa, descartar derivas en las señales y validar la continuidad en la transmisión de datos \[15\].  | J.M |
| **10/09/26** | E | **Montaje:** El diseño de ±2°Cla carcasa permitirá un ensamblaje modular y no invasivo en composteras domésticas estándar. El módulo de control y la pantalla interactiva se fijarán de forma segura en la parte externa (en la tapa o caras laterales) mediante abrazaderas o soportes atornillables. Los sensores se introducirán hacia el interior mediante perforaciones ajustadas y selladas con empaquetaduras, evitando fugas de gases o ingreso de insectos \[9\], \[10\]. | J.M |
| **20/08/26** | E | **Transporte:** El sistema deberá contar con un **peso y tamaño adecuados para facilitar su traslado de manera manual** entre diferentes ambientes. Asimismo, los sensores y componentes electrónicos deberán permanecer protegidos durante su movilización para evitar golpes, humedad o desconexiones. Además, el diseño del contenedor permitirá su reubicación sin necesidad de utilizar equipos especiales de transporte. | M.P |
| **20/08/26** | D | **Uso:** Se contempla que **CompostTech** pueda utilizarse en espacios domésticos, educativos o áreas destinadas al tratamiento de residuos orgánicos. Asimismo, el sistema deberá funcionar frente a variaciones normales de temperatura y humedad propias del proceso de compostaje. Por otro lado, los componentes electrónicos deberán encontrarse protegidos del contacto directo con los residuos, la humedad y posibles salpicaduras. Además, la pantalla incorporada deberá mostrar de manera sencilla el estado del compost y las recomendaciones necesarias para facilitar su cuidado por parte del usuario.  | M.P |
| **20/08/26** | E | **Mantenimiento:** ●       **Sensores y componentes en contacto con el compost:** deberán ser de fácil acceso para su inspección, limpieza y reemplazo. Asimismo, los sensores de temperatura y humedad deberán poder retirarse sin desmontar completamente el sistema. ●       **Componentes electrónicos:** el ESP32, la pantalla y los módulos electrónicos deberán estar protegidos de la humedad y ubicados de manera que puedan revisarse o reemplazarse fácilmente en caso de falla. Además, se deberá verificar periódicamente el estado de las conexiones y de la alimentación eléctrica \[10\]. | J.M |
|   | E | **Costos:** Para la elaboración del prototipo se buscará utilizar componentes electrónicos y materiales disponibles en el mercado nacional y de fácil reposición. Asimismo, se priorizarán alternativas de bajo costo sin comprometer el funcionamiento del sistema. De acuerdo con los componentes considerados para el prototipo, se estima un presupuesto aproximado de **S/300 a S/400**, considerando sensores, ESP32, pantalla, alimentación, contenedor y materiales de integración. Además, se buscará que el diseño permita reemplazar piezas sin necesidad de cambiar todo el sistema.  | B.M |
